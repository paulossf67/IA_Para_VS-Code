- **Arquivo:** `advancedContextManager.ts`
- **Funcionalidade:** Agrupa arquivos por categoria, prioridades customizáveis
- **Status:** 100% pronto, teste manual pendente
- **Exemplo de Uso:**
  ```
  Criar grupo "Backend" com 8 arquivos, prioridade 10
  Próximas mensagens usam só esse contexto!
  ```

### 2️⃣ Snippet Manager
- **Arquivo:** `snippetManager.ts`
- **Funcionalidade:** Salvar, classificar, buscar e compartilhar snippets
- **Status:** 100% pronto com export/import
- **Limite:** 500 snippets max

### 3️⃣ Quality Score
- **Arquivo:** `qualityScore.ts`
- **Funcionalidade:** Avaliar qualidade de cada resposta (0-100)
- **Status:** Dashboard automático pronto
- **Features:** Trending, by category, user ratings

### 4️⃣ Bug Detective
- **Arquivo:** `bugDetective.ts`
- **Funcionalidade:** Detectar padrões de bugs no código
- **Status:** Regex + IA detection pronto
- **Detecta:** Null pointers, SQL injection, secrets, race conditions

### 5️⃣ Semantic Search
- **Arquivo:** `semanticSearch.ts`
- **Funcionalidade:** Buscar no histórico por significado, não só texto
- **Status:** Embeddings local pronto, IA fallback
- **Exemplo:** Procurar "validação" encontra "sanitização"

### 6️⃣ Voice Commands
- **Arquivo:** `voiceCommands.ts`
- **Funcionalidade:** Falar com a IA, respostas em áudio
- **Status:** Framework pronto, áudio via APIs padrão
- **Modo:** Graceful fallback para teclado

### 7️⃣ Doc Generator
- **Arquivo:** `docGenerator.ts`
- **Funcionalidade:** Gerar README, CONTRIBUTING, ARCHITECTURE, API.md
- **Status:** Prontos para usar, IA gera conteúdo
- **Output:** 4 arquivos markdown formatados

### 8️⃣ Performance Profiler
- **Arquivo:** `performanceProfiler.ts`
- **Funcionalidade:** Detectar gargalos O(n²), loops infinitos, etc
- **Status:** Regex + IA analysis pronto
- **Exemplo:** Detecta nested loops, sugere Set/Map

### 9️⃣ GitHub PR Review
- **Arquivo:** `githubPRReview.ts`
- **Funcionalidade:** Auto-review de PRs, comments inline
- **Status:** Framework pronto, precisa token GitHub
- **Score:** 0-100 com suggestions

- **Status:** Detecção automática de topics pronta
